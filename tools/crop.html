图片比例裁剪

按固定比例裁剪：1:1 头像、9:16 竖屏、16:9 封面，或 Stable Diffusion 常用的 512 / 768 / 1024 画布。拖动裁剪框，实时看到输出尺寸，PNG 无损导出。

这些比例用在哪

1:1 是头像与商品图；9:16 是手机竖屏与短视频封面；16:9 是视频与桌面壁纸；3:2 / 2:3 接近相机原图。Stable Diffusion 1.5 常用 512×512、512×768，SDXL 常用 1024 一档——选定比例后再把长边设成对应尺寸，直接得到可用的画布。

关于「无损」

长边选「原始像素」且格式选 PNG 时，裁剪只做像素搬运，不重采样、不再压缩，是真正的无损。选了 512 / 768 / 1024 会做一次高质量缩放；JPEG 和 WebP 是有损压缩，体积更小，质量滑块只对这两种格式生效。

触屏也能用

裁剪框的拖动和 8 个手柄都走 Pointer 事件，手机和平板上直接拖就行。框外的暗区就是要裁掉的部分，右侧「输出」实时显示最终像素尺寸。
