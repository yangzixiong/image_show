提示词正反词分离

把从网页、Discord 或 JSON 里复制来的提示词粘进来，工具自动判断分隔格式，拆成正面词与负面词两栏；没认出来的内容单独列出，不会被静默丢掉。

粘贴原始提示词
识别顺序：JSON 字段 → Positive / Negative prompt 标签 → ### 分隔线 → --no 参数 → 空行。
正面词 Positive
负面词 Negative
未识别内容
分隔格式没覆盖到的部分，手动挪进上面两栏。

五种分隔格式，按顺序识别

先看是不是 JSON（带 prompt / negative_prompt 字段），再找 Positive: / Negative prompt: 标签行，接着是整行的 ### 分隔线（NovelAI 风格），然后是 Midjourney 的 --no 参数（取到行尾），最后才是空行分隔。先命中的先用；标签行允许正面词不带标签、由 Negative prompt: 收尾——这正是 A1111 复制按钮的输出格式。

没识别出来怎么办

认不出任何分隔时，整段会被当作正面词，负面词留空等你手动填，下方会明确显示「未识别」。用了标签但某些行落在标签之外，这些行进「未识别内容」框——工具从不静默丢内容，三栏一目了然。

拆开之后

两栏各自有复制按钮，粘进 A1111 或 ComfyUI 对应的框即可；负面词还可以去「负面词库」继续勾选拼接。反过来，用空行分隔的正反一对粘回本工具，还能验证刚才的拆分是否可逆。
