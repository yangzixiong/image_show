CLIP Token 计数与 75/77 上限

「75 个词」的说法满天飞，但 75 和 77 各指什么、超了到底发生什么，很少有人说清。这篇把计数口径、分段规则和核对方法一次讲透。

token 不是词：模型的第一步是切分

文本编码器读不到「词」，只能读一串整数。提示词进模型前会先过 BPE 分词器：常见组合合并成大 token，生僻组合拆成小碎片。SD1.5 与 SDXL 用的 CLIP 词表只有约 49000 个条目，切分结果和你平时用的输入法、英文分词都不一样——「masterpiece」可能是一个 token，也可能被拆成两段，一切以词表的合并规则为准。

这条链路上有两个直接后果：一是同一个词在不同模型里 token 数不同，CLIP、T5、GPT 的词表各管各的，计数必须按目标模型选口径；二是权重、逗号、空格都占 token——(word:1.4) 里的括号和数字不是免费的，写进提示词就要计入长度。

75 与 77 到底怎么算

CLIP 文本编码器一次最多吃 77 个位置，这是模型结构写死的上限。这 77 个位置里，开头要放一个起始标记、结尾要放一个结束标记，所以真正留给提示词文本的只有 75 个 token——「每段 77、实际 75」的两个数字就是这么来的，它们不是两种标准，而是一句话的两种口径。

说法数的是什么什么时候用
77 / 段含首尾 2 个特殊 token 的编码器总长计数器显示 x/77、判断是否贴上限
75 / 段纯提示词可用长度规划一段里能塞多少内容
512（T5-XXL）SD3 系列的文本编码上限换 SD3/Flux 类模型时按新上限算
无硬上限（o200k/cl100k）GPT 系列 tiktoken 口径给 ChatGPT 写提示词时用

本站的 Token 计数器 按 CLIP 真实词表分段统计，每段显示 x/77，超出的段标红——因为它把特殊 token 也算了进去，所以「接近 77」和「还剩 75 里的多少」说的是同一件事。

BREAK 与 AND：分段的两种姿势

超长提示词不是整体截断到 77，而是按段分批编码。BREAK 是强制断段符：写到它就开新一段，每段独立走一遍 77 上限，段与段之间不共享注意力。想让两组概念各占一半画面时，BREAK 是最直接的工具；但段数也不是越多越好——段间联系弱，前面段落的描述对后面段落的影响会明显下降。

AND 是另一套语法：把两段描述按交替权重揉进同一张图，多数前端实现里 AND 两侧也按独立段落编码。不同工具对 AND 的计数口径有差异，本站计数器按主流的 BREAK 分段口径统计，用 AND 前建议把两侧分别粘进去数一遍，别依赖一次统计盖住两种语法。权重语法本身见《提示词权重 (a:b) 完整指南》，它的作用范围同样以段为界。

超限之后画面发生什么

单段超过 77 的部分会被截断，而不是报错——这是排查「明明写了却不出」的第一现场。截断只砍尾部，所以后果和书写顺序强相关：把主体词堆在句尾，最容易被砍掉的就是主体；反过来，关键概念靠前写、或用括号独立成组，能保住优先级。

另一个隐蔽影响是权重的作用域：权重只在自己所在的段内生效。超过 75 字后的强力词，即使没被截断，也和前文隔了段，「全句强调」的效果打折。判断方法很直接：用计数器看超限标红的段里有没有关键概念，有就挪位置或拆段，而不是继续加权重数值。

中文为什么「贵」一倍

CLIP 词表以英文为主，汉字会被 BPE 拆成大量低效碎片，一个汉字通常占 1-2 个 token，而英文一个常用词往往就是 1 个。同样一句描述，中文版可能吃掉两倍长度，更快撞上 75 的墙。两个实用结论：给 SD 写提示词一律用英文，中文只做草稿；需要中文对照时用提示词翻译转一遍，既省 token 又避免生造词被切碎。负面提示词同理——它和正面共享同一套计数规则，见《负面提示词怎么写才有效》。

在 ImageLab 里逐段核对

  1. 打开Token 计数器，模型选「CLIP（SD1.5 / SDXL，77/段）」——词表离线内置，打开本页才按需加载，不出网；
  2. 粘贴完整提示词，看分段列表：每段显示 x/77，标红的段就是会被截断的段；
  3. 换模型口径复核：SD3 系换 T5-XXL（512，词表暂未内置、结果为粗估），给 GPT 写提示词换 o200k / cl100k 精确计数；
  4. 改写后把红段挪短，再进生成端——顺手用权重计算器确认挪动后括号组的等效乘数没算错。

常见问题

75 和 77 到底差在哪？

差在数不数首尾两个特殊 token：编码器总长 77，纯文本可用 75。计数器显示 x/77 是为了和「贴上限」的判断对齐，两个口径描述的是同一个限制。

超过 77 会报错吗？

不会。单段超限直接截断尾部，排在最后的内容最易丢；正确做法是 BREAK 分段或精简，而不是指望报错提醒。

中文一个字几个 token？

通常 1-2 个，且碎片化严重。提示词正文用英文几乎总能显著省长度，中文留作注释。

T5 / SD3 也受 75 限制吗？

不受。T5-XXL 上限 512，另一套 SentencePiece 词表；本站计数器已列出口径，但词表暂未内置，显示为粗估，够用来判断量级。
