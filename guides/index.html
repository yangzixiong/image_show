全部教程

十二篇，按你手上的文件类型分组。每篇都对应一个能直接打开的工具，不是泛泛的概念介绍。

看不懂图片时先读这四篇

深度图打开全黑、取到的颜色和设计稿对不上、想知道某个像素到底是不是纯黑——这类问题先看文件本身，再谈处理。

16bit TIFF 深度图 毫米单位约定、伪彩色与排错 16bit TIFF 像素查看指南 坐标、放大镜与像素网格 本地 图片取色指南 HEX/RGB 换算与取偏的原因 本地 图片直方图指南 曝光、裁切与双图对齐 本地

要交付成品图时读这三篇

裁剪、抠图、切格都有各自的几何问题。先定比例和边界，再导出，返工次数会少很多。

社交平台图片尺寸 1:1、4:5、9:16 怎么选 发布尺寸 抠图做 ControlNet 遮罩 透明 PNG 与黑白遮罩的区别 ControlNet 九宫格分镜与漫画 等分切割、路线选择与留白 本地

写提示词时读这三篇

权重的括号怎么算、负面词该删哪些、为什么提示词会被截断——这三件事决定了模型到底读到了什么。

提示词权重指南 (a:b) 语法、算式与安全区间 SD 语法 负面提示词指南 反向引导原理与按图挑词 SD 语法 Token 计数与 75/77 上限 BPE 分词、BREAK 分段与截断 SD 语法

视频与工作流

抽帧和深度控制都属于“先准备素材，再交给模型”。素材错一步，后面调参很难补回来。

视频抽帧做 AI 动画 帧率、时间点与 200 帧上限 视频不上传 深度图 ControlNet 指南 喂图前的量程、单位与排查 ControlNet

怎么用这些教程

手上有一个打不开的文件，从第一组开始；要做一张要发布的图，从第二组开始；模型不听话，先看第三组里和 Token 有关的那篇。每篇末尾都有对应工具的入口，读完可以直接试。

教程里写的尺寸、上限和字段都来自当前工具的实现或公开规范。平台规则和模型版本会变，遇到对不上的地方，以你本地的实际结果为准。
