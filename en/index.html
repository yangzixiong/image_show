AI prompts

The text you send to the model gets the same treatment: parse weight syntax like (word:1.3) and flag errors, split positive and negative prompts, tick phrases to build a negative, generate random prompts, translate tag vocabularies and count tokens. The word lists live in the page itself, so your commercial prompts never touch someone else's server.

Why everything runs locally

  • Images never leave the browser — the page has no upload endpoint, and editing keeps working offline.
  • Prompts never hit a server — dictionaries and tokenizer tables load with the page, so nobody reads what you wrote.
  • No accounts, no quotas, no watermarks — open a tool, use it, download a clean file.
