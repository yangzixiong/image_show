How to use the guides

If a file will not open, start with the first group. If you need to publish an image, start with the second. If the model is ignoring you, read the token guide before changing the sampler. Every guide ends with a link to the tool it describes, so you can test the advice on your own file.

Sizes, limits and field names come from the current implementation or a public specification. Platform rules and model versions change; when something disagrees, trust what your own file and browser do.
