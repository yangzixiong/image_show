Video Frame Grabs for AI Animation

More frames is not the same as better frames. Decide what the batch is for, then pick the interval and the resolution, and only then export.

Three jobs, three sampling rates

The same ten-second clip can need five images or three hundred. The difference is what you plan to do with them.

JobSuggested intervalFrames from 10 secondsNote
Composition, style, shot referenceEvery 1–2 seconds5–10Pick key moments; no need to cover every second
Key poses and action beatsA list of timestamps5–20Sample at transitions, not on a fixed grid
Rotoscoping, frame-by-frame animationEvery frame, or close to it240–300Split the clip: the tool caps a run at 200 frames

A 24 fps clip contains 240 frames in ten seconds; 30 fps contains 300. The frame extractor caps one run at 200 frames, defaults to 20, and accepts intervals down to 0.05 s (about 20 fps). True frame-by-frame work means splitting the video into shorter segments or exporting an image sequence from an editor.

Interval, frame rate and timestamps are different inputs

"One frame every 0.5 seconds" is an interval. "24 frames per second" is a frame rate. "At 3.2 s and 7.8 s" is a timestamp list. The tool has a mode for each; do not type seconds into a frame-count field.

Interval 0.5 s  →  about 20 frames from 10 seconds
24 fps           →  240 frames from 10 seconds
Timestamp list   →  0.5, 1.2, 3, 7.5 (seconds)

Interval mode is for even sampling. Timestamp mode is for "only these moments". Separate timestamps with commas, spaces or newlines. Zero starts at the beginning. Points beyond the clip duration are ignored rather than raising an error.

What the browser can and cannot decode

Whether extraction works depends on the browser's decoder. Chrome and Edge usually handle H.264 MP4 and VP9 WebM. HEVC (H.265), AV1 and ProRes often fail, depending on the operating system. If the file will not open, convert it to H.264 MP4 or WebM in an editor first.

Timestamps come from the browser's seek behaviour. An editor's timecode and the frame the browser lands on can differ by a frame or two, especially with Long GOP codecs. For strict rotoscoping, grab one frame and check it before running the batch.

Memory and file size

Grabbed frames stay in the page until you reload or close it. Two hundred 1080p PNGs can occupy roughly 400 MB, which is enough to make a low-memory machine stutter. Three ways to reduce the load:

  • Set the output width to 1280 or 854 instead of original 4K;
  • Use JPEG or WebP; keep PNG for transparency or lossless work;
  • Grab no more than 50 frames per run, export the ZIP, then start the next segment.

A 1080p PNG frame is often over 2 MB. JPEG is usually an order of magnitude smaller. Reference images do not need PNG; masks and cutouts do.

Workflow

  1. Drop the video into the frame extractor. Decoding happens locally; nothing is uploaded.
  2. Choose interval, timestamp list or current frame. Scrub the preview first and confirm the video plays.
  3. Set a small frame cap for the first run, 10–20 frames. Check that the images match the timestamps before scaling up.
  4. Pick an output width and format. For AI reference, 1280 plus JPEG is usually enough; for masks, original plus PNG.
  5. Start extraction and wait for the progress bar. Thumbnails are ordered by time; look for black or duplicate frames.
  6. Download the ZIP. If one frame is wrong, move the playhead and grab the current frame again.

Using the frames

For AI animation reference, five to ten key poses beat two hundred near-identical frames. Small differences teach the model nothing and add queue time.

For rotoscoping, split by action, extract each segment separately and name the folders by time range. Default filenames carry the source name and frame index; without a folder label, matching them later becomes guesswork.

For storyboards, pair the frames with the storyboard timer to fix durations. If you need a contact sheet, assemble it in a layout app; the nine-grid guide covers the reverse operation, cutting a sheet into panels.

FAQ

Why does nothing happen when I drop a video in?

Most likely the codec is unsupported. HEVC, AV1 and ProRes fail in many browsers. Convert to H.264 MP4 or WebM and try again.

Can I sample more often than every 0.05 seconds?

Not in interval mode. A timestamp list can be denser, but the 200-frame cap still applies. For true per-frame export, use an editor.

The frames do not match my editor's timecode. Why?

The browser seeks with its own decoder, so the exact frame can differ slightly. Trust the image, not the seconds.

Is the video saved anywhere?

No. It is decoded inside the page and released on reload. Exported frames exist only in the ZIP you download.
