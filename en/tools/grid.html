Where a grid split helps

Nine-tile carousel posts, photography showcases, slicing a long image into pages for a layout, or rough-cutting print sheets. Rows and columns can differ — 1×3 gives horizontal strips, 3×1 vertical ones.

Tiles are pixel-perfect

Cut edges follow floor(i × size ÷ n): tiles never overlap, no pixel is lost, and rounding remainders land on the edge tiles. Each tile exports as lossless PNG, and the zip container stores them without compressing again.

Naming

Files are named “original_r<row>c<col>.png” — photo_r2c3.png is row 2, column 3. Lay them back in order and the original image reassembles.
