Prompt Splitter

Paste a prompt copied from a site, Discord or JSON export: the tool figures out the separator format and splits it into positive and negative boxes. Anything it cannot classify is listed on its own — nothing is dropped silently.

Five separator formats, tried in order

First it checks for JSON with prompt / negative_prompt fields, then Positive: / Negative prompt: label lines, then a full-line ### separator (NovelAI style), then the Midjourney --no flag (rest of the line), and finally a blank line. The first match wins — and the positive half does not need a label of its own when a Negative prompt: line closes the paste, which is exactly what A1111's copy button produces.

When nothing is recognised

The whole paste becomes the positive prompt, the negative box stays empty for you to fill, and the status line says so explicitly. If labels were found but some lines fell outside them, those lines land in Unclassified content — the tool never drops text silently; all three boxes stay visible.

After the split

Each box has its own copy button: paste straight into the matching field in A1111 or ComfyUI, or keep building the negative half in the negative prompt library. In reverse, a positive/negative pair separated by a blank line can be pasted back into this page to check that the split round-trips.
