Flip, Rotate & Mirror an Image

Mirror horizontally or vertically, rotate 90 or 180 degrees, preview live and export. The output carries no EXIF orientation tag, so no viewer will rotate it a second time.

When you need this

A generated image came out mirrored, a scan is oriented the wrong way, you need a flipped copy of a symmetric asset, or a UI screenshot has to face the other direction for a doc. None of that is worth opening Photoshop — drop the file in, press a button or two, export.

Rotating swaps width and height

A 90-degree turn in either direction swaps the dimensions: 1920×1080 becomes 1080×1920. Flips and rotations stack, one press each, and the output size box always shows the result before you export. Reset returns to the original orientation.

Which export format

PNG is lossless but large and keeps transparency; JPEG is small but has no alpha channel, so transparent areas are flattened onto white; WebP gives better quality at the same size and is supported by every current browser. The quality slider only affects JPEG and WebP.
