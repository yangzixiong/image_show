Random Prompt Generator

One draw from each of six layers — quality, subject, action, scene, lighting and camera — combined into a prompt you can paste straight into Stable Diffusion. Reroll a single layer you dislike, lock the ones you like, and the same seed always yields the same set: copy the share link and your friends see exactly what you drew.

Output

Each layer handles one job

The quality layer holds tags like masterpiece and best quality; the subject layer decides who is drawn and with which hair; the action layer controls pose and expression; the scene layer picks the environment; the camera layer adds depth of field, focal length and framing. Every layer holds twenty-plus weighted entries — common tags draw more often than obscure ones, so the combinations stay varied without wandering off into rarity for its own sake.

Locks, rerolls and seed reproduction

“Reroll” on a row redraws only that layer; once a layer is locked, “Reroll all” leaves it alone — handy for fixing the subject first and then cycling the lighting. The seed at the top is the only source of the whole set: the same seed with the same pool always produces the same output, and typing a seed by hand reproduces it too. “Copy share link” writes the current seed into the URL, so anyone opening the link sees the same prompt. Manual single-layer tweaks are not encoded in the link; the link reproduces that seed’s full draw.

Tag list versus natural language

Tag-list mode joins the picks with commas — the format A1111, ComfyUI and other tag-first frontends expect. Natural-language mode swaps in sentence fragments for the same entries and concatenates them, which suits SD3 and Flux models that read whole sentences better. Both modes use the same draw; switching only changes the phrasing, never the random result.
